### F1: Fassen Sie in Stichworten zusammen, wofür die drei vorgestellen Layoutmethoden gedacht sind. Nennen Sie für jede zwei mögliche Anwendungsbereiche für eine gedachte realistische Website.
+ **Flaots**:
  + Elemente seitlich verlegen, damit Text sie umfließt
  + Mögliche Anwendungsbereiche: Produktbilder bei Verkaufsseiten
+ **Flexbox**:
  + Einreihung oder einspaltung in einer Dimension (Ausrichtung und Reihenfolge der Elemente)
  + Mögliche Anwendungsbereiche: Buttons, Icon-Reihe, Auflistung von Seiten (oder anderes)
+ **CSS Grid**:
  + Layouts in zwei Dimensionen und präzise platzierbare Bereiche (Header, Content, usw.)
  + Mögliche Anwendungsbereiche: Grundlayouts von Seiten, Bilder(Galerien), Reiter
