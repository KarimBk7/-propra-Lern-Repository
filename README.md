## How the practicum works

The practicum replaces lectures with independent topic work. For every assignment you answer comprehension questions in writing, log your work at the command line, and have the assignment accepted individually by a tutor. Assignments that do not pass are returned for revision.

## What each topic folder contains

| File type | Content |
| --- | --- |
| `*.md` | Answers to the assignment questions, in my own words |
| `*.prot` | Terminal logs recorded while working, including failed attempts and error messages |
| `*.py`, `*.go`, `*.sql`, `*.sh`, `*.html`, `*.js` … | Runnable example code and scripts |
| `*.crlf` | Raw HTTP requests used in the HTTP assignments |

Time spent per assignment is recorded in the commit message, for example `%js-DOM-Einführung 2.25h`.
